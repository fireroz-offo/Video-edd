# Sound Design
- Cue sheet in studio/audio/timing.json: time, type (sfx|music|vo), file, gain_db, note.
- Whooshes on camera travel, soft impact on text land, low riser before reveals, subtle tick for data counters.
- Music: ambient/pulse bed around -18 LUFS, voice around -14 LUFS, duck -12 dB under voice.
- Use only royalty-free or user-owned audio. Do not invent files that do not exist; list required files for the user to supply.
- Leave 150-300 ms silence before the key line.
