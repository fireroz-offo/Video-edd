# Visual Storytelling
1. Split script into beats (one idea per beat, 3-8 s).
2. For each beat choose a concrete metaphor (compounding = snowball of stacks, bias = distorted lens).
3. Storyboard row: scene id, time range, voiceover line, visual, camera, text on screen, sfx cue, transition.
4. Hierarchy: one hero element, max two supporting. Text <= 7 words on screen.
5. Hook in first 3 s for Shorts; end with a clear takeaway/CTA frame.
