# Video-edd

AI motion-graphics studio: script → 3D scenes → rendered MP4 with sound effects, voiceover, music and subtitles.

The project lives in [`ultimate-ai-motion-studio/`](ultimate-ai-motion-studio/). Start with its [README](ultimate-ai-motion-studio/README.md):

    cd ultimate-ai-motion-studio
    npm install
    npm run check
    npm run smoke          # quick 3-second test build
    npm run build:short    # full 1080x1920 video

`ultimate-ai-motion-studio.zip` is the original archive that the "Unzip Studio" workflow extracted; the folder is the maintained copy.
